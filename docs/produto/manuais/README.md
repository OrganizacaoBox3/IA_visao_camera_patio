# Manuais — Visão de Pátio

Guias práticos de consulta para conectar dispositivos e operar o sistema.

| Manual | Para quê |
|--------|----------|
| [**Incluir câmeras reais e relevantes** (comece aqui)](./manual-incluir-cameras.md) | Guia de ponta a ponta: escolher a câmera certa por modo (atividade/objetos/leitura/fadiga), descobrir na rede, montar a URL RTSP, cadastrar na UI "+ Câmera IP", configurar zonas/linhas e resolver problemas. |

| [Leitores industriais (Sick / Cognex)](./manual-leitores-industriais.md) | Leitores de código/visão industrial — **não são RTSP**: como integram (TCP/MQTT/EtherNet-IP…), caminho de evento/indicador (throughput, tempo sem leitura) e quando há MJPEG. |
